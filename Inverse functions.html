Asymptotes & Features
IB Syllabus Core Takeaway

The graph of y = f−1(x) is a reflection of y = f(x) in the line y = x. If point (a, b) lies on f, then (b, a) must lie on f−1. Consequently, f(f−1(x)) = x.

Real-Life Application 1 (Linear Modeling)

Smart Thermostat & Weather Sensor Calibration

Linear Mapping: °C ↔ °F

A digital weather station's internal sensor records physical temperature in Celsius (C), but standard displays output readings in Fahrenheit (F). The forward function F = f(C) converts Celsius to Fahrenheit. When a user dials in a preferred target in Fahrenheit, the smart microcontroller uses the inverse function C = f−1(F) to set the physical heating coil in Celsius!

Forward Function f(C)

Celsius → Fahrenheit
F(C) = (9/5)·C + 32
25.0 °C
Calculated Display Output: 77.0 °F

Inverse Function f−1(F)

Fahrenheit → Celsius
C(F) = (5/9)·(F − 32)
77.0 °F
Reconstructed Sensor Signal: 25.0 °C

Step-by-Step IB Algebraic Method: Reversing the Relationship

STEP 1: State relationship y = (9/5)x + 32
STEP 2: Interchange x and y x = (9/5)y + 32
STEP 3: Rearrange for y x − 32 = (9/5)y ⇒ y = (5/9)(x − 32)
STEP 4: Write f⁻¹(x) f⁻¹(x) = (5/9)(x − 32)
Real-Life Application 2 (Quadratic & Square Root Modeling)

Forensic Crash Reconstruction: Skid Marks vs. Vehicle Speed

Quadratic / Root Mapping: v ↔ d

Automotive engineers express emergency braking distance d (in meters) as a quadratic function of initial speed v (in km/h): d(v) = k · v² (where k depends on surface friction). When responding to a crash scene, police officers measure the skid mark length d with a measuring tape and apply the inverse function v(d) = √(d / k) to determine if the vehicle was speeding!

Road Parameters & Mode Select

Investigation Result Forward Mode
Vehicle Speed (v) 80 km/h
Skid Mark Length (d) 38.4 m
Emergency Brakes Applied Skid: 38.4 meters
Physics Domain Restriction: Since d = k · v² is quadratic, standard algebra gives v = ±√(d/k). However, vehicle speed cannot be negative in physical space (v ≥ 0). Restricting the domain of f(v) to [0, ∞) guarantees a valid one-to-one function that possesses an inverse!

Teacher Lesson Strategy & IB Pedagogy

1. Inquiry & Real-World Hook

Begin with the Thermostat or Skid Mark scenario. Ask: "If a function turns an input into an output, how do we reverse engineer the input from an observed result?"

2. Visual Symmetry & Domain Swap

Use the Graph Lab. Have students observe reflection across y = x. Show why quadratic f(x) = x² requires domain restriction x ≥ 0 to pass the Horizontal Line Test.

3. Rational Asymptote Reflection

Select Rational f(x) = (2x + 1)/(x − 3). Point out how the vertical asymptote of f (x = 3) becomes the horizontal asymptote of f−1 (y = 3).

IB Exam-Style Questions with Markschemes

[4 Marks] SL Paper 1 Style Topic 2.5: Rational Inverses

Let f(x) = (2x + 1) / (x − 3), for x ∈ ℝ, x ≠ 3.

  1. Find an expression for f−1(x).
  2. State the domain and range of f−1.

(a) Markscheme:

Let y = (2x + 1)/(x − 3) ⇒ x = (2y + 1)/(y − 3) (M1: swap x and y)

x(y − 3) = 2y + 1 ⇒ xy − 3x = 2y + 1 (M1: expand)

xy − 2y = 3x + 1 ⇒ y(x − 2) = 3x + 1 (A1: factorize y)

f⁻¹(x) = (3x + 1) / (x − 2) (A1)

(b) Markscheme:

Domain of f⁻¹ = Range of f: x ∈ ℝ, x ≠ 2 (A1)

Range of f⁻¹ = Domain of f: y ∈ ℝ, y ≠ 3 (A1)

[5 Marks] SL Paper 2 Style Topic 2.2: Restricted Domain Quadratic

Consider g(x) = 2(x − 1)² + 3, for x ≥ 1.

  1. Explain why g(x) possesses an inverse function for x ≥ 1.
  2. Find g−1(x) and state its domain.

(a) Markscheme:

For x ≥ 1, g(x) is strictly increasing and thus one-to-one (passes the Horizontal Line Test). (R1)

(b) Markscheme:

Set y = 2(x − 1)² + 3 ⇒ x = 2(y − 1)² + 3 (M1)

(x − 3) / 2 = (y − 1)² (M1)

y − 1 = √((x − 3)/2) (A1: take positive root since y ≥ 1)

g⁻¹(x) = 1 + √((x − 3) / 2) (A1)

Domain of g⁻¹: x ≥ 3 (since Range of g is y ≥ 3) (A1)
